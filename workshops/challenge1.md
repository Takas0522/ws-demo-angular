# コードからドキュメントの概要を把握する

このアプリケーションがどのような機能を提供するのか。あるいはどのような目的で提供されているのかを把握する必要があります。  
まずはGtiHub Copilotを使用しコードから概要のドキュメントを作成します。  
アプリケーション全体の概要、機能単位を分離しての説明、機能および機能の使い方の説明をGitHub Copilotに実施してもらいます。
下記のプロンプトを下敷きにアレンジを少し加えながらドキュメントを作成しましょう。

``` markdown
現在参照するこのワークスペースにはドキュメントが不足している為ドキュメントを作成します。  
作成したドキュメントは `/docs` 内に格納します。ドキュメントのIndexをとるために、ルートディレクトリのREADME.mdに追記します。  
ドキュメントは長大になることを防ぎたいので大項目ごとにファイルを分離してください。  
下記のドキュメントを作成してください。
<!-- 以下自由に調整可能 -->
- アプリケーション全体の概要
- アプリケーションの役割・機能
  - 複数の機能を持つようであれば分割して記載
- アプリケーションの利用シナリオの想定
- デバッグの方法
- データ構造と初期データについて
```
