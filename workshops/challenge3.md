# 作成したドキュメントを利用する

作成したドキュメントとソースコードを利用して作業を実施してみます。  
新しい機能を追加する場合を想定して利用する形で構成します。  

## 仕様考案時のチェックリストの作成

Askモードの実行でもOKです

``` markdown
新しい機能を提供するためのドキュメントを作成しようとしています。
作成するドキュメントは現在提供されているドキュメントと同水準の情報が提供される必要があります。
作成されたドキュメントをレビューするためのチェックリストを考案してください。
```

## テストデータの作成

DBのテストデータの作成、またはリクエストデータの作成などが行えます。  
Askモードの実行でもOKです。

DBのテストデータの作成

``` markdown
多数データある場合の挙動の検証の為テストデータの作成を行いたいです。
ユーザー一覧に表示されるデータを50件ほど想定しています。関連テーブルの更新も含めてサンプルデータを作成してください。
```

WebAPIのテストデータの作成

``` markdown
ユーザー作成のWebAPIの挙動を確認したいです。各項目の最大長ちょうどとなるようなパラメータとなるリクエストを作成して下さい。
PowerShellで実行できる形式のコマンドにしてください。
```
